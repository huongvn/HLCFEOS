# Cài đặt Ubuntu OS và đổi password mặc định

1. Chuẩn bị trước khi cài đặt
    ```
    Luckfox Pico 86 Development Board
    USB Type-A to Type-C data cable
    100M/1000M Ethernet cable and router
    USB-to-TTL module
    ```
2. Cài đặt upgrade_tool trên ubuntu 
    ```
    sudo unzip upgrade_tool_v2.17.zip
    cd upgrade_tool_v2.17_for_linux/
    sudo cp upgrade_tool /usr/local/bin
    sudo chmod +x /usr/local/bin/upgrade_tool
    ```
3. Kết nối wifi vào luckfox lấy địa chỉ IP của board 
    hoặc cắm dây usb sử dụng địa chỉ ip mặc định của buildroot qua cổng usb : 
    USB Static IP Address: ```172.32.0.93```
    Quy trình dưới sử dụng ssh qua cổng usb-c

4. Đổi IP của máy tính cùnd dải 172.32.0.X sau đó SSh vào luckfox bằng ip 172.32.0.93
    ```ssh root@172.32.0.93```

    ```
    Username: root
    Password: luckfox
    ```

    ```[root@luckfox root]# ```
5. Sau khi ssh thành công Chạy lệnh sau 
    ```reboot loader```
    Board sẽ khởi động lại vào chế độ Boot loader
6. Kết nối usb -c vào máy tính
    ```lsusb```
    Xem kết quả trả về có dòng dưới là kết nối và vào chế độ boot thành công
    ```Bus 001 Device 008: ID 2207:110c Fuzhou Rockchip Electronics Company ```
7. Vào thư mục chứa os "Ubuntu_Luckfox_Pico_Ultra_W_EMMC_250313", rồi chạy lệnh sau :
    ```sudo upgrade_tool uf update.img```

    Khi trả về log sau thì thành công 
    ```
    Loading firmware...
    Support Type:1106	FW Ver:0.0.00	FW Time:2025-03-18 17:57:36
    Loader ver:1.01	Loader Time:2025-03-18 17:54:11
    Start to upgrade firmware...
    Download Boot Start
    Download Boot Success
    Wait For Maskrom Start
    Wait For Maskrom Success
    Test Device Start
    Test Device Success
    Check Chip Start
    Check Chip Success
    Get FlashInfo Start
    Get FlashInfo Success
    Prepare IDB Start
    Prepare IDB Success
    Download IDB Start
    Download IDB Success
    Download Firmware Start
    Download Image... (100%)
    Download Firmware Success
    Upgrade firmware ok.
    ```
    Luckfox sẽ khởi động lại và màn hình sẽ hiển thị giao diện terminal login 
    Có thể ssh vào bo mạch khi kết nối qua cổng usb-c

    ```
    Username: pico
    Password: luckfox
    USB Static IP Address: 172.32.0.70
    ```
8. Thiết lập đổi password của bo mạch
    ```
    passwd
    Changing password for pico.
    Current password: 
    New password: 
    Retype new password: 
    passwd: password updated successfully
    ````
    
    thông tin ssh mặc định mới : 
    ```
    Username: pico
    Password: luckfox@1234
    ```

# (OPTION) Bỏ qua pass khi thực hiện các lệnh qua SSH 

Để chạy các lệnh `sudo` qua SSH mà không cần phải nhập lại mật khẩu mỗi lần, bạn có thể cấu hình file **`sudoers`** bằng cách cấp quyền `NOPASSWD` cho tài khoản của bạn.

---

## Các bước thực hiện

1. **Mở file cấu hình sudoers bằng visudo:**
Đăng nhập vào Luckfox Pico qua SSH và chạy lệnh sau (luôn luôn dùng `visudo` thay vì mở file trực tiếp bằng `nano` để tránh lỗi cú pháp làm hỏng quyền root):

```bash
sudo visudo

```


2. **Thêm cấu hình NOPASSWD:**
Kéo xuống cuối file và thêm dòng sau vào (thay `ubuntu` bằng tên user SSH của bạn nếu dùng user khác):

```text
ubuntu ALL=(ALL) NOPASSWD: ALL

```

> **Mẹo thao tác:**
> * Nếu `visudo` mở bằng `nano`: Thêm dòng trên vào cuối, nhấn `Ctrl + O` -> `Enter` để lưu, `Ctrl + X` để thoát.
> * Nếu `visudo` mở bằng `vim`: Nhấn `G` để xuống cuối file, nhấn `i` để bật chế độ chỉnh sửa, gõ nội dung vào. Chỉnh xong nhấn `Esc`, gõ `:wq` rồi nhấn `Enter` để lưu và thoát.
> 
> 


3. **Kiểm tra lại cấu hình:**
Mở một cửa sổ SSH mới (hoặc đăng xuất ra đăng nhập lại) và chạy thử một lệnh `sudo` bất kỳ:

```bash
sudo apt update
# hoặc
sudo systemctl status

```

Nếu hệ thống thực thi ngay mà không hỏi mật khẩu là bạn đã thành công.


---

## 💡 Mẹo nâng cao (Tùy chọn)

### 1. Chỉ miễn mật khẩu cho 1 lệnh cụ thể

Nếu không muốn bỏ mật khẩu cho tất cả lệnh `sudo` vì lý do bảo mật, bạn có thể chỉ định rõ từng lệnh cụ thể (ví dụ: lệnh khởi động lại mạng):

```text
ubuntu ALL=(ALL) NOPASSWD: /usr/sbin/service, /sbin/reboot

```

### 2. Dùng file cấu hình riêng (Sạch sẽ hơn)

Thay vì sửa trực tiếp file chính `/etc/sudoers`, bạn có thể tạo một file cấu hình riêng trong thư mục `/etc/sudoers.d/`:

```bash
sudo visudo -f /etc/sudoers.d/nopasswd_ubuntu

```

Nhập nội dung duy nhất sau vào file rồi lưu lại:

```text
ubuntu ALL=(ALL) NOPASSWD: ALL

```
